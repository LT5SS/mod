# Minecraft 1.20.1 Forge - 红宝石军工与魔法全集 (Ruby Arsenal & Magic)

这是一个功能完备的 Minecraft 1.20.1 Forge 模组工程，涵盖装备体系、防具套装技能、特殊魔法功能道具、矿物生态及云端自动构建配置。

---

## 一、 包含内容一览

### 1. 武器与工具体系
- **红宝石剑 (Ruby Sword)**：高额攻击伤害与攻击速度，击中敌人自动附加 **5 秒烈火焚烧** 与 **虚弱 II** 负面效果。
- **全套红宝石工具**：红宝石镐 (Ruby Pickaxe)、红宝石斧 (Ruby Axe)、红宝石锹 (Ruby Shovel)、红宝石锄 (Ruby Hoe)。拥有超越钻石的挖掘速度与高达 2200 点的高耐久。

### 2. 护甲与套装被动技能 (Set Bonus)
- **红宝石护甲全套**：头盔、胸甲、护腿、靴子。
- **套装被动联动**：当玩家同时装备全部 4 件红宝石防具时，自动激活套装共鸣被动技能：
  - **永久防火 (Fire Resistance)**：免疫岩浆与火焰伤害。
  - **抗性提升 (Resistance)**：大幅降低受到的各类物理与魔法伤害。
  - **力量 I (Strength)**：提供近战攻击力加成。

### 3. 特殊魔法与功能性道具
- **烈焰法杖 (Fire Staff)**：右键向准心方向发射烈焰火球，具有 1 秒内置冷却。
- **雷霆权杖 (Staff of Thunder)**：右键准心锁定 40 格内的方块，直接召唤天降雷霆落雷打击！
- **磁铁护符 (Loot Magnet)**：随身携带（放入背包或副手）时，自动产生磁场吸附周围 8 格范围内的所有掉落物。
- **虚空闪现石 (Warp Blink Gem)**：右键向前瞬间闪现跃迁 10 格，伴随末影人传送音效，探索与脱险神器。
- **附魔红宝石苹果 (Enchanted Ruby Apple)**：顶级金色食物，食用后提供高额生命恢复、抗性提升、防火及 4 层伤害吸收护盾。

### 4. 矿石与方块生态
- **红宝石矿石 (Ruby Ore)** 与 **深层红宝石矿石 (Deepslate Ruby Ore)**：自然开采掉落丰富经验，支持精准采集与时运加成。
- **红宝石块 (Block of Ruby)**：由 9 颗红宝石合成，高硬度装饰与储存方块。

### 5. 原版合成与熔炼配方
- 涵盖所有工具、武器、护甲、法杖、磁铁、苹果的九宫格合成台配方。
- 包含矿石的原版熔炉与高炉快速烧炼配方。

## 二、 两种构建运行方式

### 方式 1：利用 GitHub Actions 云端一键自动生成 .jar（免本地环境）
本工程已贴心地为您预装了 `.github/workflows/build.yml` 工作流文件：
1. 将此工程上传到您的 GitHub 仓库。
2. GitHub 的云端虚拟机会自动检测并触发编译任务，自动下载 Forge 和 Minecraft 库完成编译。
3. 编译完成后，直接在 GitHub 网页端的 **Actions -> Artifacts** 即可免费下载最终生成的 `.jar` 文件！

### 方式 2：本地电脑构建
1. 使用 IntelliJ IDEA 打开本文件夹。
2. 确保已安装 JDK 17。
3. 运行 `./gradlew build`（Windows 运行 `gradlew build`）。
4. 编译完成的成品 `.jar` 位于 `build/libs/` 目录下。
